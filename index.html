Selected projects

Cisco Systems

Platform engineering, networking, OS observability, and applied AI.

01

Robotnik Hot-Pluggable Edge Module

Worked as a platform engineer on bring-up of the hot-pluggable Robotnik module: NFS filesystem bring-up, Docker-supported implementation, datapath design, and benchmarking for AI-related workloads. The broader SONiC architecture addressed power and boot sequencing, image and bootloader placement, TPM validation, application lifecycle, diagnostics, shell access, backplane configuration, resource statistics, and DPDK.

02

IEEE 802.1Qbu TSN Frame Preemption

Implemented low-latency frame preemption on the Industrial Ethernet 9000 so time-critical traffic can interrupt non-critical frames mid-transmission. Delivered firmware changes, QoS integration for express and preempted queues, per-port CLI configuration, and auto-enable negotiation.

03

Graph-Grounded PHY/Port Debugging

Built a Graph RAG agent for link flaps, CRC bursts, and SFP failures across the Port → PHY → SerDes → ASIC chain. Parsed CLI output with TextFSM, combined causal graph traversal with documentation retrieval, and reduced complex-fault triage from roughly 60 minutes to 5 minutes.

04

LLM-Driven Code Review

Built specialized LLM agents that inspect pull requests for bugs, security, performance, and maintainability. Code knowledge graphs, semantic embeddings, confidence-weighted aggregation, static-analysis signals, and developer feedback improve cross-file reasoning and finding quality.

OPLUS India R&D

Generative AI and ML systems for mobile platforms.

05

On-Device Generative Vision

Contributed to a Magic Eraser-style feature for intelligent object removal and background synthesis using generative ML models. Also built structured ML failure-detection pipelines and lightweight LLM-assisted log analysis.

Indian Institute of Technology Madras

Research and systems projects.

06

Federated 5G VNF Orchestration

Designed federated deep-learning systems for VNF resource allocation in multi-domain 5G networks using LSTM/GRU forecasting and Time-GAN synthetic telemetry. Developed privacy-preserving auto-scaling and dynamic placement across multi-cloud environments without sharing raw domain data.

07

GPU TLB Optimization: DUCATI

Implemented a simplified DUCATI architecture in Macsim to extend GPU TLB reach. Benchmarked merge-sort CPU and vector-add GPU workloads and observed fewer TLB evictions than the baseline on GPU workloads.

08

Packet Processing and Router Algorithms

Built Python circuit-switching and packet-processing simulators and implemented IPv4 classification using a Set Pruning Trie for CS6040.

09

zRAM for Constrained Linux Systems

Evaluated compressed in-memory swap through algorithm selection, adaptive sizing, swap priority, swappiness tuning, zswap conflict avoidance, and validation with zramctl and swapon.
