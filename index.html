Research direction

Intelligent systems for next-generation networks.

I aim to investigate how operating-system mechanisms, programmable network infrastructure, and distributed machine learning can work together to make future networks faster, more autonomous, and more dependable. My industry and research experience gives me a full-stack perspective—from hardware bring-up and kernel observability to datapath design, federated learning, and network orchestration.

At IIT Madras, I designed a federated learning framework for VNF auto-scaling using LSTM/GRU forecasting and Time-GAN synthetic telemetry, and developed a federated deep-learning system for dynamic VNF placement across multi-cloud environments without sharing raw operator data.

Selected projects

Cisco Systems

Platform engineering, networking, OS observability, security, and applied AI.

01

Linux Kernel Systems and eBPF Monitoring

Worked on Linux kernel-level systems and eBPF-based monitoring to improve runtime visibility into system and network behavior. Applied kernel-level observability signals to vulnerability mitigation and operational diagnosis on production networking platforms.

02

Robotnik Hot-Pluggable Edge Module

Brought up a CN10208-based compute module with eight Neoverse N2 cores, 32GB DRAM, and NVMe storage for SONiC switches. Implemented NFS, Docker application support, datapath design, resource telemetry, and AI-workload benchmarking, and contributed to boot, TPM, diagnostics, backplane, lifecycle, and DPDK design.

03

zRAM for Constrained Linux Systems

Evaluated compressed in-memory swap to increase effective memory capacity while avoiding slow storage I/O. Tuned compression algorithms, device sizing, swap priority, and swappiness; prevented zswap conflicts and validated behavior using zramctl and swapon.

04

IEEE 802.1Qbu TSN Frame Preemption

Implemented low-latency preemption so time-critical traffic can interrupt non-critical frames during transmission. Developed platform firmware changes, CLI extensions, and QoS integration for express and preempted queues, with per-port configuration and link-partner auto-enable negotiation.

05

PoE Platform Features, Firmware Upgrades, and SELinux

Developed PoE platform features and firmware boot-time upgrade support for production networking systems. Enforced SELinux policies to constrain platform services and strengthen runtime security.

06

Edge AI Hardware Power Fingerprinting

Built a containerized Cisco IOx pipeline that learned device-specific signatures from Layer-1 PoE power, current, and voltage telemetry using Isolation Forest. Detected rogue-device replacement and integrated automated closed-loop port isolation.

07

Graph RAG Agent for PHY/Port Debugging

Modeled Port → PHY → SerDes → ASIC dependencies and combined TextFSM-based CLI parsing with graph traversal to explain link flaps, CRC bursts, and SFP failures. Reduced average engineer triage time from approximately 60 minutes to 5 minutes for complex PHY faults.

08

AI-Powered Code Review Platform

Built specialized LLM agents for bugs, security, performance, and maintainability, grounded by code knowledge graphs, semantic embeddings, and static-analysis signals. Used confidence-weighted aggregation and developer feedback to improve cross-file reasoning and finding quality.

09

Vulnerability Context Enrichment for Cisco Cyber Vision

Transformed generic NVD CVE records into device-specific risk profiles by correlating vulnerabilities with asset configurations and active protocol services. Incorporated ISA/IEC 62443 zone context to improve operational relevance and vulnerability prioritization.

Indian Institute of Technology Madras

Computer architecture and networking systems projects.

10

GPU TLB Optimization: DUCATI Architecture

Implemented a simplified DUCATI architecture in MacSim to extend GPU TLB reach and reduce address-translation inefficiency. Benchmarked CPU merge-sort and GPU vector-add workloads, observing fewer TLB evictions than the baseline on GPU workloads.

11

Router Architectures and Algorithms — CS6040

Built Python circuit-switching and packet-processing simulators and implemented IPv4 classification using a Set Pruning Trie.
