Experience & selected projects

01 · Cisco Industrial Ethernet 9000

IEEE 802.1Qbu TSN Frame Preemption

Implemented low-latency frame preemption so time-critical traffic can interrupt non-critical frames mid-transmission. Delivered the end-to-end platform support: firmware changes, QoS integration for express and preempted queues, per-port CLI configuration, and auto-enable negotiation that activates preemption only when both link endpoints support it.

02 · VMware URF · IIT Madras

Federated Learning for 5G Network Orchestration

Designed federated deep-learning systems for VNF resource allocation in multi-domain 5G networks. The work covered LSTM/GRU-based resource forecasting, Time-GAN synthetic telemetry, privacy-preserving auto-scaling, and dynamic VNF placement across multi-cloud environments without sharing raw domain data. It resulted in three peer-reviewed IEEE publications.

03 · SONiC platform architecture

Robotnik Hot-Pluggable Edge Module

Defined the software architecture for a pluggable CN10208 module with eight Neoverse N2 cores, 32GB DRAM, and NVMe storage to extend SONiC switch compute and application capacity. The design addressed whole-system power-on and boot sequencing, image and bootloader placement, TPM-based IOSE validation, IOx application lifecycle without IOS CLIs, SONiC access to logs and crash dumps, shell access, backplane modes, boot-stage connectivity, CPU/memory/application statistics, and DPDK integration.

04 · Linux memory subsystem

zRAM for Constrained Linux Systems

Evaluated compressed in-memory swap as an alternative to slow disk swapping. The project covers zstd/lz4/lzo-rle trade-offs, adaptive sizing, swap priority, swappiness tuning, zswap conflict avoidance, distribution-specific deployment with zram-generator or zram-tools, and validation with zramctl and swapon.

05 · IIT Madras · Macsim

GPU Address-Translation Reach

Implemented a simplified DUCATI architecture based on the work “High-performance Address Translation by Extending TLB Reach of GPU-accelerated Systems.” Benchmarked CPU merge sort and GPU vector-add workloads and observed fewer TLB evictions than the baseline on GPU workloads.

06 · IIT Madras · CS6040

Packet Processing and Router Algorithms

Built Python simulators for circuit switching and packet processing, and implemented IPv4 packet classification using a Set Pruning Trie to study router architecture and lookup behavior.
