Experience & selected projects

01 · Cisco Systems

Deterministic Ethernet on Linux

Implemented IEEE 802.1Qbu TSN Frame Preemption on the Industrial Ethernet 9000, including firmware, QoS queues, per-port CLI, auto-negotiation, PoE, eBPF observability, and SELinux.

02 · VMware URF · IIT Madras

Federated 5G VNF Orchestration

Designed federated-learning systems for VNF auto-scaling and placement across multi-domain and multi-cloud 5G networks, using forecasting and synthetic data while preserving domain privacy.

03 · SONiC platform

Robotnik Edge Compute Module

Defined the software architecture for a hot-pluggable CN10208-based edge module: power and boot sequencing, image location, bootloader, TPM validation, IOx application lifecycle, SONiC shell and telemetry access, crash diagnostics, backplane modes, and DPDK integration.

04 · Linux kernel

Compressed-Memory Swap

Optimized zRAM for constrained systems through algorithm selection, adaptive sizing, swappiness tuning, zswap conflict avoidance, and verification with zramctl and swapon.

05 · GPU architecture

DUCATI Address Translation

Implemented and evaluated a simplified DUCATI architecture in Macsim to study GPU TLB reach and reduce address-translation inefficiency.
